## Logihelper

**Logihelper** - веб-инструмент с локальной LLM для обучения основам цифровой схемотехники, в частности построению схем в программе `Logisim`.

___

**Основы**:
1. Выбирается легковесная языковая модель, строгое ограничение - около 4 GB VRAM.
2. Легковесная языковая модель оборачивается в Retrieval-Augmented Generation (RAG) систему, необходимую для формирования контекста у легковесной модели.
3. RAG дает модели контекст из курса кибернетики, а также основ программы Logisim.
4. Система предполагает наличие математического (вычислительного) модуля, который способен обрабатывать операции не только относящиеся к простой арифметике, но и к операциям в АЛУ, мультиплексоре и прочих цифровых схемах.
5. Кроме того, система предполагает наличие парсера, делающего logisim-файл формата .circ (видоизмененный .xml) в простой, сжатый и читаемый для модели и человека, вид.

## Структура проекта

- `main.py` — точка запуска веб-приложения.
- `logihelper/` — модули ассистента, поиска, вычислений, памяти и журналирования.
- `data/model_docs.json` — база знаний для поиска контекста.
- `web/` — HTML-страница и статические файлы CSS и JavaScript.
- `scripts/` — вспомогательные скрипты.

При запущенной Ollama веб-приложение можно открыть через `python main.py`. Для запуска ассистента в консоли выполните `python -m logihelper.assistant_main` из корня проекта.
